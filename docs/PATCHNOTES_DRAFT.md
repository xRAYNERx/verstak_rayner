# Черновик патчноута

## Чат

- Улучшена работа длинных чатов: Verstak быстрее открывает большие переписки и подгружает ранние сообщения по кнопке
- Исправлена кнопка остановки модели: остановка применяется к текущему ответу и не должна сбивать работу другой модели
- Улучшено копирование текстовых блоков из ответа: кнопка копирования переносит текст в буфер обмена вместе с нумерацией
- Добавлен просмотр файлов из ответа модели в боковой панели чата
- Для файлов, которые нельзя открыть, показывается понятное сообщение вместо технической ошибки

## Проекты

- Окно "Проект" переименовано в "Управление проектом"
- В настройках проекта исправлено отображение русских текстов
- Улучшена работа файлового дерева в больших проектах: тяжёлые папки показываются компактнее и не замедляют интерфейс
- Вкладки "Браузер" и "Дизайн" временно закрыты и помечены как "Скоро"

## Уведомления

- Исправлено поведение всплывающих уведомлений: прозрачная область вокруг уведомления больше не должна перекрывать клики по приложению

## Прогоны AI
